Text Expander — Privacy Policy

Last updated: October 5, 2026

TL;DR: Text Expander does NOT collect, store, or transmit any user data. All your snippets and settings are stored locally in your browser. No analytics, no telemetry, no cloud servers.

1. Data Collection

Text Expander does not collect, store, or transmit any personal data or browsing data.

  • No analytics or tracking
  • No telemetry or crash reporting
  • No cloud servers or remote databases
  • No account or login required
  • No data sold or shared with third parties

2. Local Data Storage

All snippets and settings are stored locally in your browser using chrome.storage.local. This data never leaves your device. It is accessible only by the extension itself and can be cleared at any time from the extension's Settings page.

3. Permissions Explained

The extension requests the following permissions, solely for its core functionality:

  • <all_urls> (host permission): Required to monitor keyboard input on web pages so that text expansion can be triggered. The extension reads keystrokes to match snippet triggers and replaces them with the expanded text. No browsing data is recorded, stored, or transmitted.
  • storage: Required to save your snippets and settings locally in the browser. Data is stored using Chrome's local storage API and never synced to any server.

4. What the Extension Does

Text Expander is a purely local tool. When you type a trigger word (e.g., ;sig), the extension replaces it with the corresponding text you defined. All processing happens in your browser — no data is sent anywhere.

5. Third-Party Services

Text Expander does not use any third-party services. There are no external API calls, no CDNs, no analytics providers, and no advertising networks.

6. Data Security

Since all data is stored locally in your browser, the security of your snippets depends on the security of your device and browser. We do not have access to your data.

7. Changes to This Policy

If the extension's data practices change, this privacy policy will be updated accordingly. Any changes will be reflected on this page.
